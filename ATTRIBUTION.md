# Project attribution

This repository contains a copy of the group project originally hosted at https://github.com/HritikBudhwar/Scalable-ride-matching-system.

Original Git history and contributor information remain available in that source repository. This destination was created as an empty repository, not a GitHub fork, so its commits record the import and subsequent changes rather than reproducing the original history.

The Rideflow UI, isolated Java demo API, tests, and DEMO.md are an AI-assisted extension prepared with Codex. See DEMO.md for implemented features and limitations.

Credit the original contributors and describe individual contributions accurately when presenting this group project.
